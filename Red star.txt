```

                     │            RED STRING             │
                     └─────────────────┬─────────────────┘
         ┌──────────────────┬──────────┴──────────┬──────────────────┐
         ▼                  ▼                     ▼                  ▼
   1. The Platform     2. Fate Sync          3. Fate Watch      4. Magic Circle
   (Shared Vault)    (Interactive Chat)     (Live Telemetry)     (Pairing/Auth)

```

### 1.1 The Platform (Shared Buffer & Artifact Drop)

* **Drag-and-Drop Dropzone:** Seamlessly drop images, lossless audio, documents, and archives between connected nodes without size degradation.
* **Dual-Tier Memory Boundary:**
* **Soft Limit:** Configurable buffer (e.g., 512 MB, 1 GB, 2 GB) that manages the active transfer session.
* **Elastic Flex Zone (+15%):** An automated buffer allowing files that slightly exceed the limit to complete gracefully rather than failing mid-transfer.
* **Hard Cap:** Strict threshold ($1.15 \times \text{Soft Cap}$) where transfers lock to prevent disk or RAM saturation.


* **Transient Auto-Purge:** Optional toggle to wipe transferred files from memory once the link between devices is severed.

### 1.2 Fate Sync (Bidirectional Communication)

* **Real-Time Interactive Messaging:** Direct chat thread between desktop and mobile with zero server intermediate.
* **Hot Clipboard Sync:** One-tap action on mobile or hotkey on desktop (`Ctrl+Shift+V`) that instantly pushes system clipboard text across devices.
* **Delivery Confirmation:** Cryptographic acknowledgment hashes ensuring every text block arrives uncorrupted.

### 1.3 Fate Watch (Zero-Latency Telemetry & Prompter)

* **Keystroke-by-Keystroke Mirroring:** Characters render in real time as they are typed on the host keyboard without waiting for an "Enter" press.
* **Operational Diff Engine:** Transmits minimal insert/delete/cursor deltas rather than the entire text payload.
* **Spectator Lock:** The watcher interface is strictly read-only, functioning as a real-time remote teleprompter or terminal feed.

### 1.4 Magic Circle QR & Runic Pairing

* **Procedural Visual Encryption:** Concentric runic bands generated dynamically using polar geometry.
* **Complexity Scaling:** The visual density, inner star geometry, and orbital rings increase automatically as larger platform memory sizes are chosen.
* **Optical Handshake:** Transmits local IP, port, and a 256-bit ephemeral Pre-Shared Key (PSK) directly into the mobile camera lens—no cloud account or pairing code required.
