### The Runic Cipher: *Knot-Script (Nodus-V1)*

To make this functional both as an **algorithmic security cipher** and a **geometric visual language** for the Magic Circle, this runic system uses a 6-bit encoding matrix (Base64-compatible).

Instead of arbitrary decorative doodles, every glyph is built on a **3×3 sacred grid** (9 bind-points) using standard compass radials. This allows the computer vision parser (OpenCV/camera) to read and decode runes radially along the circle’s orbital rings, while functioning as a cryptographic substitution table.

```
       Visual Grid (Bind Points)
             (0,2)───(1,2)───(2,2)
               │   \   │   /   │
             (0,1)───(1,1)───(2,1)
               │   /   │   \   │
             (0,0)───(1,0)───(2,0)

```

### 3. Cryptographic Security Layer: *The Knot-Cipher*

Using the runes as raw character replacement is a simple substitution cipher. To make this **cryptographically robust against local network sniffing**, Red String uses a **Dynamic Spiral Feistel Round**:

$$\text{CipherRune}[i] = (\text{PlainByte}[i] \oplus \text{KeyByte}[i \pmod{32}] \oplus \text{Salt}[i]) \pmod{36}$$

1. **Ephemerality:** The Secret Key is generated per session using 256-bit entropy.
2. **Radial Salt:** The salt changes based on the rune's angle ($\theta$) on the Magic Circle:

$$\text{Salt}[i] = \lfloor (i \cdot \phi) \times 256 \rfloor \pmod{64}$$



*(where $\phi$ is the golden ratio $\approx 1.618$)*.
3. **Double-State Obfuscation:** Even if an observer photographs the Magic Circle, the runes cannot be decrypted without knowing the current session initialization timestamp embedded in the center QR core.

#### Canvas Vector Rendering Function

Every letter translates into stroke commands on the canvas:

```javascript
// Runic dictionary vector definition (normalized 0.0 to 1.0)
const RUNES = {
  'A': [[0,0, 0.5,1], [0.5,1, 1,0], [0.25,0.5, 0.75,0.5]],
  'F': [[0,0, 0,1], [0,1, 1,1], [0,0.5, 0.6,0.5]],
  'K': [[0,0, 0,1], [1,1, 0,0.5], [0,0.5, 1,0]],
  'S': [[1,1, 0,1], [0,1, 0,0.5], [0,0.5, 1,0.5], [1,0.5, 1,0], [1,0, 0,0]],
  'T': [[0,1, 1,1], [0.5,1, 0.5,0]],
  // ... other letters mapped to the 3x3 normalized grid
};

/**
 * Draws a rune at an exact angle and radius along the Magic Circle
 */
function drawRuneAtAngle(ctx, char, angle, radius, size) {
  const strokes = RUNES[char.toUpperCase()];
  if (!strokes) return;

  ctx.save();
  // Move to orbital point along circle circumference
  ctx.translate(
    canvas.width / 2 + Math.cos(angle) * radius,
    canvas.height / 2 + Math.sin(angle) * radius
  );
  // Orient rune perpendicular to the radial spoke
  ctx.rotate(angle + Math.PI / 2);

  ctx.strokeStyle = '#E63946'; // Crimson
  ctx.lineWidth = 1.5;
  ctx.shadowColor = '#FF2A54'; // Scarlet glow
  ctx.shadowBlur = 6;

  for (const [x1, y1, x2, y2] of strokes) {
    ctx.beginPath();
    ctx.moveTo((x1 - 0.5) * size, (y1 - 0.5) * -size);
    ctx.lineTo((x2 - 0.5) * size, (y2 - 0.5) * -size);
    ctx.stroke();
  }

  ctx.restore();
}

```

### Visual & Practical Value

1. **Aesthetic Identity:** Anyone looking at your desktop screen sees a glowing crimson runic magic circle rather than an ordinary black-and-white square barcode.
2. **Deterministic Geometry:** Because each letter is composed strictly of lines between points on a 3×3 matrix, the mobile app's computer vision pipeline can decode runes with basic line-detection (Hough Line Transform) even under uneven lighting.
3. **Payload Verification:** The outer rune ring spells out the SHA-256 hash checksum of the session connection string, allowing instant visual validation that the connection has not been intercepted.
